# Деплой сайта на reg.ru — пошаговая инструкция

Гайд для тех, кто никогда раньше не выкладывал сайты. Время прохождения от нуля до работающего сайта — ~30 минут.

---

## Что у нас есть

- Репозиторий: `github.com/ansyz43/kinowhite` (ветка `main`)
- Проект на Astro → собирается командой `npm run build` в папку `dist/`
- Форма заявок шлёт письма на **dvfilmaward2026@mail.ru** через `public/api/lead.php` (PHP-обработчик)
- Что нужно от хостинга: PHP 7.4+ (есть на любом тарифе reg.ru), функция `mail()` (включена по умолчанию)

---

## Шаг 1. Купить хостинг

1. Зайти на **https://www.reg.ru** → войти в личный кабинет (или зарегистрироваться).
2. Открыть **«Хостинг»** в верхнем меню → нажать **«Заказать хостинг»**.
3. Выбрать тариф **«Host-Lite»** или **«Host-1»** — самые дешёвые, нам этого хватит.
   - Параметры: PHP 7.4+, SSL бесплатно, поддержка `.htaccess`.
4. Оплатить. Через 2–5 минут в кабинете появится новый «Заказ» со статусом «Активен».

---

## Шаг 2. Открыть панель управления хостингом

1. Личный кабинет reg.ru → раздел **«Мои услуги»** → **«Хостинг и серверы»**.
2. Найти заказ, нажать **«Войти в панель управления»** (ISPmanager или cPanel — зависит от тарифа, дальнейшие шаги одинаковы).
3. В письме от reg.ru сразу после покупки придут:
   - Адрес панели
   - Логин (обычно `u1234567`)
   - Пароль
   - Адрес временного домена вида `u1234567.test.tw1.ru` — на нём уже можно открыть сайт сразу после загрузки, не дожидаясь покупки нормального домена.

---

## Шаг 3. Привязать домен (или использовать временный)

### Вариант A — у вас уже куплен домен на reg.ru

1. В панели хостинга: раздел **«Сайты»** → **«Создать сайт»**.
2. Имя сайта — ваш домен (например `dvkinopremiya.ru`).
3. Тип — **«Сайт на статичном файле»** или **«PHP-сайт»**. Выбрать **PHP**.
4. Версия PHP — **8.1** или новее.
5. Корневая папка — оставить по умолчанию (обычно `public_html` или `www`).

### Вариант B — используем временный домен (для теста)

В панели уже создан сайт по адресу `u1234567.test.tw1.ru`. Ничего настраивать не нужно — переходите к шагу 4.

---

## Шаг 4. Собрать сайт у себя на компьютере

> Если этот шаг уже сделан тем, кто пишет код — пропускайте и берите готовую папку `dist/`.

В терминале:

```bash
git clone https://github.com/ansyz43/kinowhite.git
cd kinowhite
npm install
npm run build
```

После этого появится папка `dist/` со всем сайтом. **Именно её содержимое мы загружаем на хостинг.**

Внутри будут файлы: `index.html`, `about/`, `submit/`, `archive/`, `_astro/`, `assets/`, `api/lead.php` — всё нужное.

---

## Шаг 5. Загрузить файлы на хостинг

### Способ 1 — через файловый менеджер reg.ru (проще)

1. В панели хостинга → **«Менеджер файлов»**.
2. Перейти в корень сайта: `public_html/` (или `www/` — зависит от тарифа).
3. **Удалить** файлы-заглушки, если они там есть (`index.html` с надписью «Сайт на reg.ru работает»).
4. Нажать **«Загрузить»** → выбрать **все файлы и папки из `dist/`**:
   - `index.html`
   - `about/`, `archive/`, `contacts/`, `expert-council/`, `news/`, `nominations/`, `orgcommittee/`, `partners/`, `privacy/`, `program/`, `regulation/`, `submit/`
   - `_astro/`
   - `assets/`
   - `api/` (тут лежит `lead.php` — обработчик формы)
   - `app.js`, `favicon.ico`, `favicon.svg`
5. Дождаться окончания загрузки (~1–2 минуты).

### Способ 2 — через FTP (быстрее для больших обновлений)

1. В панели → **«FTP-аккаунты»** → создать аккаунт или взять данные основного.
2. Скачать **FileZilla** (https://filezilla-project.org/).
3. В FileZilla ввести:
   - Хост: `имя-сервера.timeweb.ru` или `ftp.вашдомен.ру`
   - Логин/пароль: из FTP-аккаунта
   - Порт: `21`
4. Слева — ваша папка `dist/`. Справа — `public_html/` на сервере.
5. Перетащить всё содержимое `dist/` в `public_html/`.

## Шаг 6. Проверить сайт

1. Открыть в браузере домен (`https://вашдомен.ру` или `https://u1234567.test.tw1.ru`).
2. Должна загрузиться главная страница с логотипом, датами 23–25 сентября, кнопками «Подать заявку» / «Архив победителей».
3. Кликать по верхнему меню: Главная, Премия (О премии, Номинации, Оргкомитет, Экспертный совет), Участие, Архив, Новости, Контакты.

Если страница не открывается:
- Подождите 5 минут (бывает кэш DNS).
- Проверьте в панели, что сайт действительно создан на этот домен.
- Проверьте через панель → **«Логи ошибок»**.

## Шаг 7. Проверить, что форма шлёт письма

1. Откройте `https://вашдомен.ру/api/lead.php` напрямую в браузере. Должен вернуться JSON:
   ```json
   {"ok":false,"error":"Method not allowed"}
   ```
   Это нормально — значит PHP запустился и обработчик жив.
   Если вместо JSON вы видите **исходный код PHP** — у вас не подключена обработка `.php` на этом сайте. В панели: «Сайты» → выбрать сайт → выставить тип «PHP-сайт».
2. На сайте: `/submit` → пройти все 3 шага формы (название фильма / имя / email) → нажать «Отправить».
3. Должен показаться зелёный экран «Заявка принята».
4. Через 10–60 секунд письмо придёт на **dvfilmaward2026@mail.ru**.

**Важно:** mail.ru очень строго фильтрует. Если письмо не пришло:
- **Проверьте папку «Спам»** в почтовом ящике — там оно почти наверняка.
- Также все заявки **дублируются в текстовый файл** `public_html/api/leads.log` на сервере. Открыть через файловый менеджер — внутри строки вида:
  ```
  [22.05.2026 14:33:12] 81.23.45.6 Иван | ivan@studio.ru | +79... | Тестовый фильм
  ```

## Шаг 8. (опционально) Чтобы письма не падали в «Спам»

Это нужно сделать **один раз**, после того как домен будет привязан.

1. В панели reg.ru → раздел **«Почта»** → создать ящик `noreply@вашдомен.ру` (можно с любым случайным паролем — мы оттуда не читаем, только шлём).
2. Открыть на сервере файл `public_html/api/lead.php` через файловый менеджер → нажать «Изменить».
3. Найти строку:
   ```php
   const MAIL_FROM     = '';                    // оставить пустым → auto noreply@<host>
   ```
   Изменить на:
   ```php
   const MAIL_FROM     = 'noreply@вашдомен.ру';
   ```
4. Сохранить.
5. В панели → **«Почта»** → **«DKIM/SPF»** → включить **SPF** и **DKIM** для вашего домена (одна кнопка). Теперь mail.ru будет принимать письма как доверенные.

После этого заявки будут приходить **сразу в основную папку**, а не в «Спам».

## Шаг 9. Обновление сайта в будущем

Когда что-то изменилось в коде:

1. На компьютере: `git pull && npm run build` (обновить и пересобрать).
2. В файловом менеджере reg.ru: войти в `public_html/`, удалить старые файлы (можно «Выделить всё» кроме `api/leads.log`), загрузить новое содержимое из `dist/`.

Или через FTP — просто перетащить заново, FileZilla сама перезапишет.

---

## Шаг 10. (опционально) Автодеплой по git push

Если не хочется каждый раз руками заливать:

1. В панели reg.ru → раздел **«Git-репозитории»** (если есть на тарифе).
2. Подключить `https://github.com/ansyz43/kinowhite.git`.
3. Указать команду сборки: `npm install && npm run build`.
4. Корневая папка вебсайта: `dist`.

После этого каждый `git push origin main` будет автоматически обновлять сайт. На дешёвых тарифах reg.ru этой опции может не быть — тогда останется ручной способ.

## Что делать если что-то не работает

| Проблема | Решение |
|---|---|
| Сайт не открывается | Подождать 10 мин (DNS). Проверить в панели, что сайт создан и привязан к домену |
| Открывается заглушка reg.ru | Удалить `index.html` от reg.ru из `public_html/`, перезагрузить страницу |
| Шрифты квадратами | Очистить кэш браузера (Ctrl+F5). Шрифты Google — должны загружаться сами |
| `/api/lead.php` показывает код PHP | В панели «Сайты» → выставить тип «PHP-сайт», версия PHP ≥ 7.4 |
| Форма «не удалось отправить» | Проверить `public_html/api/leads.log` — если запись есть, значит дошло, но `mail()` отвалилась (вопрос к SPF/DKIM, шаг 8) |
| Письма попадают в «Спам» | См. шаг 8 — настроить SPF/DKIM, переключить `MAIL_FROM` на ящик на своём домене |
